# SPAVR 代码实现计划

## 原则

- **C-JEPA 是第三方库，不改动。** 位于 `third_party/cjepa/`，只 import、只加载权重，不改其源码。
- 我们的代码全部放在 `Code/SPAVR/` 下，通过在 C-JEPA 的隐空间外**加头 / 包一层**来实现，不侵入。
- 两种训练策略各一个独立脚本：策略1 冻结 C-JEPA 全部只训头；策略2 冻结 encoder、训 predictor + 头。通过 `requires_grad` + 优化器控制，不改源码。
- 产出统一打包成一个 ckpt（C-JEPA + head 端到端），不单独拆出 head。图像 encoder 恒为官方 videosaur 权重。

## 目录结构（计划新增）

```
Code/SPAVR/
├── third_party/cjepa/          # 第三方库，只读不改
├── docs/                       # 已有：方案设计、导读
├── spavr/                      # 我们的包
│   ├── __init__.py
│   ├── backbone.py             # 加载C-JEPA；控各部件requires_grad，取z、rollout、锚loss
│   ├── heads.py                # 方案A：注意力池化分位数头 + pinball loss
│   ├── uncertainty.py          # 方案B：ensemble/预测误差 → 认知风险
│   ├── energy.py               # 方案C：能量/异常头 + 负样本构造
│   └── model.py                # 组装 RewardRiskModel + 打包保存/加载
├── configs/                    # 我们的训练/评测配置（不碰cjepa/configs）
│   ├── frozen.yaml             # 策略1
│   └── finetune_predictor.yaml # 策略2
├── train/
│   ├── train_frozen.py             # 策略1：冻结C-JEPA全部，只训头
│   └── train_finetune_predictor.py # 策略2：冻结encoder，训predictor+头（带锚loss）
├── scripts/
│   └── train.sh
└── tests/
    └── test_smoke.py           # 用假数据跑通forward/loss的冒烟测试
```

## 模块职责

| 模块 | 对应方案 | 做什么 |
|---|---|---|
| `backbone.py` | 通用 | 加载 C-JEPA ckpt，控各部件 `requires_grad`，输出 z `(B,T,S+2,D)`、rollout、锚 loss |
| `heads.py` | A | 注意力池化(对象槽) → MLP → 单调 [q10,q50,q90]；含 pinball loss |
| `uncertainty.py` | B | ensemble 分歧 / rollout 误差 → 风险分（无标签） |
| `energy.py` | C | 能量头 + 负样本，正低负高（无标签） |
| `model.py` | 组装 | `RewardRiskModel`（`score`）+ 打包保存/加载 |
| `train_frozen.py` | 策略1 | 冻结 C-JEPA 全部，只训头 |
| `train_finetune_predictor.py` | 策略2 | 冻结 encoder，训 predictor + 头，带锚 loss |

## 开发阶段

1. **搭骨架**：`backbone.py` 加载 C-JEPA，`model.py` + `heads.py`（方案 A 注意力池化分位数头），`test_smoke.py` 用假数据跑通 forward + pinball loss。
2. **策略1**：`train/train_frozen.py` 打通训练循环（冻结 C-JEPA 全部，return-to-go 目标，假标签先），验证分位数能学出宽度，打包保存。
3. **策略2**：`train/train_finetune_predictor.py`（冻结 encoder，训 predictor + 头，带锚 loss，优化器参数组）。
4. **无标签风险（可选路线）**：`uncertainty.py`(B)，可选 `energy.py`(C)。
5. **接真数据 / 评测**：替换假标签，接 C-JEPA 的 slot pkl 与 AP 数据。

## 备注

- 第 1–4 阶段全程可用**假数据/假标签**跑通，不依赖数据集下载。
- 与 C-JEPA 的唯一耦合点是 `backbone.py`（import 其 `MaskedSlot_AP_Predictor`、加载权重、按策略控冻结）。
- 方案 A 是主线；方案 B/C（无标签）是可选替代路线，编号与 `C-JEPA奖励风险模型-方案设计.md` 一致。
